### Tolga Zorlu

Software engineer in Istanbul. I build and ship full-stack web and mobile products end to end: product idea, data model, API, UI, App Store review, deploy and the boring parts after launch.

Most of my work is TypeScript (Next.js, React Native / Expo, NestJS) on Postgres and Supabase, plus Go for command-line tools. Lately I spend a lot of time on LLM features that are cheap to run and safe to expose to users.

**Shipped apps** (iOS, built solo under Viby Studio)

- **Barcode: Mobile POS**: point of sale for small shops: scan a barcode, ring up the sale, follow the day from home screen widgets.
- **EsnafQR**: QR menus and price lists for small businesses, 7 languages.
- **Repertuar**: lyrics and chords notebook for musicians.
