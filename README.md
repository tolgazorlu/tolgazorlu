### Tolga Zorlu

I ship mobile and web products end to end (Expo, Next.js, Supabase) and build small Go CLIs that both people and AI agents can drive.

**Start here**

- **[btrack](https://github.com/tolgazorlu/btrack)**: a time tracker you use in one line, which also logs your Claude Code, Codex and Hermes sessions. CLI + MCP. `brew install tolgazorlu/btrack/btrack`
- **[dborm](https://github.com/tolgazorlu/dborm)**: paste a Drizzle, Prisma, TypeORM or Mongoose schema and get a live ER diagram plus a review. [Live](https://dborm.vercel.app)
- **[presskit](https://github.com/tolgazorlu/presskit)**: a free press kit website template for indie game developers.

### How I build tools

Every tool starts as a CLI with `--json` output, ships an MCP server and an agent skill in the same binary, keeps your data on your machine, and installs in one line.
